# **Document 2: Product Requirements & Website System Guide**

## **Read & Revive / አንባቢ**

**Version:** 0.1  
**Status:** Draft for discussion and locking  
**Purpose:** To define how Read & Revive works as a long-term product system, starting from the public website and growing into user accounts, reading cycles, streaks, badges, leaderboards, reflections, and youth publishing.

---

# **1\. Product Vision**

## **1.1 Product Goal**

Read & Revive should become more than a website.

It should become a **reading habit system** where young people in Ethiopia can:

* Discover selected books  
* Join organized reading cycles  
* Follow clear reading timelines  
* Discuss ideas with peers  
* Submit reflections  
* Attend closing sessions  
* Publish writings  
* Build reading streaks  
* Earn badges  
* Track growth over time  
* Become part of a visible reading culture

The website is the public face, but the long-term product is a **gamified reading community platform**.

---

# **3\. Core Product Model**

The whole product should be built around one main object:

# **The Reading Cycle**

A reading cycle is a structured book journey.

## **3.1 Reading Cycle Flow**

Book selected  
→ Cycle announced  
→ User joins  
→ Reading timeline begins  
→ Daily/weekly reading progress  
→ Reflections submitted  
→ Group discussions happen  
→ Closing session held  
→ Articles submitted  
→ Best reflections/articles published  
→ Readers receive recognition

---

## **3.2 What a Reading Cycle Contains**

Each reading cycle should have:

| Item | Description |
| ----- | ----- |
| Book | The selected book |
| Cover image | Visual identity of the cycle |
| Description | Short reason why the book was selected |
| Start date | When the cycle begins |
| End date | When the reading period ends |
| Reading duration | Example: 14 days, 21 days, 30 days |
| Daily target | Pages or chapters per day |
| Discussion link | Telegram/Facebook group |
| Weekly prompts | Reflection questions |
| Closing session | Final review/discussion event |
| Reviewer/expert | Person leading the final session |
| Submission deadline | For reflections/articles |
| Rewards | Badges, certificates, recognition |
| Status | Upcoming, active, completed |
