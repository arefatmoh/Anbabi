# **Document 4: UI/UX Design System & Interaction Guide**

## **Read & Revive / አንባቢ**

**Version:** 0.1  
**Status:** Draft for discussion and locking  
**Purpose:** This document defines the full visual system, layout behavior, illustration style, doodle language, interaction rules, and UI direction for Read & Revive. It will become the main reference when creating Figma screens, UI images, prompts, and later development components.

---

# **1\. Core UI Vision**

Read & Revive should not feel like a normal landing page, NGO website, education website, or AI-generated template.

It should feel like:

**A playful digital reading movement where books, challenges, reflections, and youth voices come alive.**

The UI must communicate these feelings immediately:

| Feeling | Meaning |
| ----- | ----- |
| **Youthful** | Fresh, energetic, not too formal |
| **Playful** | Doodles, scribbles, badges, tilted cards, lively sections |
| **Gamified** | Progress, streaks, levels, badges, timelines |
| **Editorial** | Strong typography, beautiful reading/blog experience |
| **Community-based** | Circles, discussions, reader voices, social proof |
| **Handmade** | Scribbles, rough highlights, imperfect shapes, human touch |
| **System-ready** | Components should work later for accounts, dashboards, badges, and profiles |

---

# **2\. Main Visual Concept**

## **“A Reading Journey Playground”**

The website should be designed around the feeling of a **reader moving through a journey**.

Not this:

Hero  
Cards  
Stats  
Blog  
Footer

But this:

Enter the movement  
→ See the current book  
→ Join the cycle  
→ Follow the reading path  
→ Unlock progress  
→ Share reflections  
→ Get featured  
→ Repeat the journey

The UI should feel like the user is joining a **living challenge**, not reading a static page.

# **3\. Design Personality**

## **3.1 Main Personality Mix**

| Personality | Percentage |
| ----- | ----- |
| Youthful/playful | 40% |
| Gamified/energetic | 30% |
| Editorial/reading-focused | 20% |
| Cultural/warm | 10% |

This means:

* It should be playful, but not childish.  
* It should be gamified, but not like a game for kids.  
* It should be editorial, but not too serious.  
* It should be culturally warm, but not overly traditional.

# **5\. Color System**

## **5.1 Brand Color Direction**

The color system should feel warm, energetic, and readable.

### **Recommended Core Palette**

| Role | Color Name | Suggested Hex | Use |
| ----- | ----- | ----- | ----- |
| Primary | Revive Orange | `#F97316` | Main buttons, highlights, active states |
| Primary Dark | Burnt Orange | `#C2410C` | Hover states, strong accents |
| Main Text | Ink Black | `#111111` | Main headings and body |
| Soft Black | Charcoal | `#232323` | Dark sections, footer |

| Info | Sky Blue | `#38BDF8` | Links, info badges |
| Error | Soft Red | `#EF4444` | Error states only |

---

## **5.2 Color Usage Rules**

### **Orange should be used for:**

* Primary CTA buttons  
* Active reading cycle highlights  
* Progress indicators  
* Badge accents  
* Important underlines  
* Doodle marks  
* Selected tabs  
* Small decorative shapes

### **Black should be used for:**

* Strong headlines  
* Footer/dark sections  
* Navigation text  
* Editorial sections  
* Badge outlines

### **Cream/warm paper should be used for:**

* Main page background  
* Blog reading background  
* Cards  
* Reading timeline sections

---

## **5.3 Important Color Rule**

Do **not** make every section orange.

Too much orange will make the website heavy and less premium.

Better rhythm:

Warm paper background  
→ Orange accents  
→ Black typography  
→ Peach cards  
→ Dark section break  
→ Orange CTA

# **6\. Typography System**

Typography is extremely important because this is a reading brand.

## **6.1 Font Personality**

The typography should combine:

| Font Type | Purpose |
| ----- | ----- |
| Bold editorial serif | Big emotional headings |
| Clean sans-serif | Body text and interface |
| Handwritten accent | Doodles, stickers, small emotional words |
| Display numbers | Stats, streaks, levels, points |

---

## **6.2 Recommended Font Pairing Direction**

### **Option A — Best for editorial \+ playful**

| Use | Font Style |
| ----- | ----- |
| Main headings | Bold serif, high personality |
| Body | Clean rounded sans-serif |
| Accent | Handwritten marker style |

Example font types:

Heading: Playfair Display / Fraunces / Libre Baskerville style  
Body: Inter / Manrope / Plus Jakarta Sans style  
Accent: Patrick Hand / Caveat / handwritten marker style

---

## **6.3 Typography Rules**

### **Headings**

Headings should be large, bold, and expressive.

Example:

Read together.  
Reflect deeply.  
Revive your mind.

Use line breaks intentionally. Do not make headings look like generic SaaS headings.

---

### **Body Text**

Body text should be clean and readable.

Recommended body size:

| Context | Size |
| ----- | ----- |
| Desktop body | 16–18px |
| Mobile body | 15–16px |
| Small labels | 12–14px |
| Blog body | 18–20px |
| Blog paragraph line height | 1.7–1.9 |

---

### **Accent Typography**

Use handwritten text for small emotional elements only.

Examples:

Today’s challenge  
Keep going\!  
New cycle  
Reader favorite

Do not use handwritten font for long paragraphs.

# **8\. Layout System**

## **8.1 Layout Should Feel Alive**

Avoid rigid equal boxes everywhere.

Use:

* Asymmetric layouts  
* Overlapping cards  
* Tilted cards  
* Floating badges  
* Curved reading paths  
* Sticker-like labels  
* Hand-drawn arrows  
* Alternating section rhythms  
* Editorial whitespace

---

## **8.2 Layout Rhythm**

A good page should have rhythm like:

Large emotional hero  
→ Active book card  
→ Playful journey path  
→ Dark contrast section  
→ Blog/editorial section  
→ Community section  
→ Final bold CTA

The website should not feel flat.

---

## **8.3 Grid System**

Use a clean grid underneath, but make the surface feel playful.

### **Desktop**

* Max content width: `1180px–1280px`  
* Main grid: 12 columns  
* Section padding: `80px–120px`  
* Card gap: `24px–32px`

### **Tablet**

* Max content width: `720px–900px`  
* Section padding: `64px–80px`

### **Mobile**

* Single-column first  
* Section padding: `48px–64px`  
* Horizontal padding: `20px–24px`  
* Cards should stack beautifully

Some cards can have slightly rotated or sticker-like styling.

Example:

or:

transform: rotate(1.5deg)

But do not overuse it. Only 10–20% of cards should feel tilted. Too much will look messy.

# **10\. Doodles, Scribbles, and Hand-Drawn System**

This is one of the most important parts.

## **10.1 Purpose of Doodles**

Doodles should make the website feel:

* Human  
* Youthful  
* Energetic  
* Handmade  
* Not AI-generated  
* Not corporate

They should support the message, not decorate randomly.

---

## **10.2 Doodle Types**

| Doodle Type | Use |
| ----- | ----- |
| Hand-drawn arrows | Guide the eye to CTAs or next steps |
| Scribble circles | Emphasize words or numbers |
| Rough underlines | Highlight important phrases |
| Stars/sparks | Celebrate progress and badges |
| Book sketches | Reading-related decoration |
| Speech bubbles | Discussion/community sections |
| Sticky notes | Prompts, reminders, quotes |
| Flame doodles | Streaks |
| Stamp marks | Completion/certificates |
| Margin notes | Blog and reflection pages |

---

## **10.3 Doodle Placement Rules**

Use doodles around:

* Hero headline  
* Main CTA  
* Current book card  
* How-it-works journey  
* Badges  
* Reflection quotes  
* Blog pull quotes  
* Final CTA section

Avoid doodles around:

* Long body paragraphs  
* Important forms  
* Dense dashboard data  
* Accessibility-critical text  
* Navigation menus

---

## **10.4 Doodle Style Rules**

Doodles should be:

* 1–2px stroke  
* Slightly rough  
* Mostly black or orange  
* Hand-drawn, not perfect vector  
* Simple and readable  
* Consistent across pages

Avoid:

* Random colorful clipart  
* Perfect corporate icons  
* Generic AI illustrations  
* Overly detailed drawings  
* Too many unrelated symbols

---

## **13.2 Secondary Button**

### **Use for:**

Explore Books  
Read Reflections

### **Style:**

* Cream background  
* Black border  
* Black text  
* Rounded pill  
* Hover: orange tint or doodle underline

---

## **13.3 Ghost Button**

### **Use for low-priority actions:**

Learn more  
View all  
Read more

### **Style:**

* No background  
* Underline or arrow  
* Hover: hand-drawn underline appears

---

## **13.4 Button Microinteraction**

Buttons should feel alive.

On hover:

* Move up `-2px`  
* Shadow increases slightly  
* Arrow moves right  
* Doodle underline appears  
* Button may rotate very slightly, maximum `0.5deg`

Avoid:

* Overly flashy animations  
* Neon effects  
* Corporate gradient buttons  
* Tiny hard-to-click buttons

* Good contrast between text and background

* Clear focus states  
* Alt text for images

# **27\. Design Anti-Rules**

These are extremely important.

## **27.1 Avoid AI/Common Website Look**

Do not use:

* Generic hero with text left and random 3D illustration right  
* Perfect equal card grids everywhere  
* Overused SaaS gradients  
* Fake testimonials  
* Generic icons from random packs  
* Abstract blobs without purpose  
* Stock photos of random people reading  
* Same border radius on everything  
* Corporate blue/white education style  
* Long blocks of text with no visual rhythm

---

## **27.2 Avoid Rigid NGO Layout**

Do not structure the website like:

About us  
Mission  
Vision  
Objectives  
Activities  
Contact us

Instead, structure it like:

Join the current cycle  
See how the reading journey works  
Build progress  
Read voices from the circle  
Become part of the movement
