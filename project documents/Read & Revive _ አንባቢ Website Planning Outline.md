# **1\. Brand Strategy Document**

This document defines **what Read & Revive is**.

## **Sections to prepare**

### **1.1 Brand One-Liner**

Example:

**Read & Revive is a youth-led reading movement helping young people in Ethiopia build consistent reading habits through book cycles, peer discussions, reflections, and community-driven content.**

### **1.2 Short Description**

Used on homepage, about page, footer, and social media.

### **1.3 Long Description**

Used for proposals, partners, sponsors, and official documents.

### **1.4 Mission**

Example:

To make reading accessible, engaging, and meaningful for youth in Ethiopia through digital content, peer-based discussion, and rewarding reading experiences.

### **1.5 Vision**

Example:

To revive a strong reading culture where young people read consistently, think critically, express ideas, and inspire positive change.

### **1.6 Core Values**

Suggested values:

* **Consistency** — building reading habits step by step.  
* **Reflection** — reading deeply, not passively.  
* **Community** — making reading social and supportive.  
* **Expression** — turning ideas into youth-written content.  
* **Growth** — using books to build purpose and confidence.  
* **Impact** — connecting reading with real-life action.

### **1.7 Brand Voice**

The tone should be:

* Energetic  
* Encouraging  
* Youthful  
* Smart  
* Warm  
* Slightly playful  
* Not too formal  
* Not too childish

Avoid:

* NGO report language  
* Boring academic wording  
* Too much religious wording on the public website  
* Generic AI-style phrases like “empowering communities through innovative solutions”

# **2\. Product Concept Document**

This explains how the website works as a product, not just as a design.

## **2.1 Main Product Idea**

The website should be built around:

# **The Reading Cycle**

A user should immediately understand this journey:

Book Selected  
→ Join Reading Cycle  
→ Read Daily  
→ Share Reflections  
→ Discuss in Community  
→ Attend Closing Session  
→ Submit Article  
→ Get Featured / Earn Recognition

This should become the heart of the website.

Current orange and black are strong. We should refine them.

| ----- | ----- |

# **5\. Gamification System Document**

This is very important. We should design the rules early.

## **5.1 Gamification Goal**

Gamification should not be random. Its goal is to help users:

* Read consistently  
* Finish books  
* Join discussions  
* Write reflections  
* Encourage others  
* Feel progress  
* Build identity as readers

---

## **5.2 Point System**

Suggested points:

| Action | Points |
| ----- | ----- |
| Join a reading cycle | 10 |
| Mark daily reading complete | 5 |
| Submit reflection | 10 |
| Comment in discussion | 5 |
| Attend closing session | 20 |
| Complete a book | 50 |
| Submit article | 40 |
| Article published | 100 |
| Invite a friend who joins | 30 |

---

## **5.3 Streak Rules**

Streaks should reward consistency, but not punish users too harshly.

### **Suggested streak milestones**

| Days | Badge Name |
| ----- | ----- |
| 1 day | First Page |
| 3 days | Consistent Starter |
| 7 days | Weekly Reader |
| 14 days | Deep Habit |
| 21 days | Cycle Finisher |
| 30 days | Revived Reader |
| 50 days | Page Warrior |
| 100 days | Culture Reviver |

### **Streak rule**

A streak continues when a user completes the daily reading task.

### **Grace rule**

Give users **1 grace day per week** so they do not lose motivation if they miss one day.

Example:

If a reader misses one day, they can recover by completing the next day’s reading and reflection.

## **5.5 Leaderboard Rules**

Leaderboards can motivate, but they can also discourage beginners. So we should use friendly leaderboards.

Recommended leaderboard types:

| Leaderboard | Purpose |
| ----- | ----- |
| Weekly Readers | Rewards consistency |
| Top Reflectors | Rewards thoughtful sharing |
| Book Finishers | Rewards completion |
| Community Builders | Rewards encouragement |
| New Readers Rising | Helps beginners feel seen |

Avoid only ranking by total points forever, because old users will always dominate.

# **10\. Design Anti-Rules**

These are important so it does not look common or AI-made.

## **Avoid**

* Plain rectangular cards everywhere  
* Generic stock photos  
* Generic “Our mission / Our vision / Our values” layout  
* Too many corporate sections  
* Too much orange at once  
* Overusing icons without meaning  
* Fake-looking testimonials  
* Random blog content not connected to books  
* A homepage that only explains instead of inviting action

## **Use instead**

* Reading journey paths  
* Current book challenge  
* Progress indicators  
* Doodles and handwritten details  
* Real reader reflections  
* Community screenshots or quotes  
* Badge previews  
* Timeline-based sections  
* “Join the cycle” language
