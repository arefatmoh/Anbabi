# **Document 3: Gamification, Streaks, Badges & Reward System Guide**

## **Read & Revive / አንባቢ**

**Version:** 0.1  
**Status:** Draft for discussion and locking  
**Purpose:** To design the long-term gamification system of Read & Revive so that reading becomes consistent, social, rewarding, and meaningful without turning the platform into a shallow points game.

---

# **1\. Core Gamification Vision**

Read & Revive should not use gamification only for decoration.

The goal is not simply to show badges, points, and leaderboards. The goal is to build a **reading habit system** that helps youth:

* Start reading.  
* Continue reading.  
* Finish books.  
* Reflect on ideas.  
* Discuss with others.  
* Write and publish thoughts.  
* Feel recognized.  
* Return for the next cycle.

The gamification system should support the full journey:

Join → Read → Reflect → Discuss → Complete → Write → Get Recognized → Repeat

---

# **2\. Main Gamification Philosophy**

## **2.1 The System Should Reward Meaningful Growth**

Read & Revive should reward actions that build real reading culture.

Reward:

| Action | Why it matters |
| ----- | ----- |
| Daily reading | Builds consistency |
| Finishing books | Builds discipline |
| Reflection | Builds thinking |
| Discussion | Builds community |
| Writing | Builds expression |
| Encouraging others | Builds healthy culture |
| Returning across cycles | Builds long-term identity |
| Helping organize | Builds leadership |

---

## **2.2 The System Should Not Reward Empty Activity**

Avoid rewarding actions that can become spam.

Do not over-reward:

* Random logins.  
* Empty comments.  
* Very short meaningless reflections.  
* Repeated copy-paste answers.  
* Clicking buttons without actual reading.  
* Competing only for points.  
* Inviting people without real engagement.

The system should feel like:

**Progress with purpose.**

Not:

**Points for everything.**

# **5\. XP and Points System**

## **5.1 Difference Between XP and Points**

To make the system stable long-term, separate **XP** and **Reading Points**.

| System | Purpose |
| ----- | ----- |
| **XP** | Long-term growth and reader level |
| **Reading Points** | Current cycle/weekly competition and leaderboard |

### **Why separate them?**

If one point system does everything, old users will dominate forever.

So:

* **XP** grows slowly and permanently.  
* **Reading Points** can reset by cycle, week, or month.

This keeps the platform fair for new users.

---

## **5.2 XP Rules**

XP should represent lifetime growth.

XP should not reset.

Users earn XP from:

* Completing reading tasks.  
* Submitting approved reflections.  
* Completing cycles.  
* Publishing articles.  
* Earning badges.  
* Helping the community.

---

## **5.3 Reading Points Rules**

Reading Points can be used for:

* Weekly leaderboard.  
* Cycle leaderboard.  
* Monthly challenges.  
* Seasonal campaigns.

Reading Points can reset:

* Weekly.  
* Per reading cycle.  
* Monthly.  
* Per special challenge.

This keeps competition fresh.

# **7\. Anti-Spam Point Rules**

To keep the system meaningful, points must have limits.

## **7.1 Daily Limits**

| Action | Daily Reward Limit |
| ----- | ----- |
| Reading check-in | Once per day |
| Daily reflection | Once per day per cycle |
| Comments | Maximum 3 rewarded comments/day |
| Encouragement | Maximum 3 rewarded encouragements/day |
| Quote sharing | Maximum 1 rewarded quote/day |

Users can still participate more, but extra activity may not earn points.

---

## **7.2 Reflection Quality Requirement**

A reflection should only receive full points if it meets basic quality.

Minimum requirement:

At least 40–60 words, connected to the book, and not copy-pasted.

Better reflection quality signals:

* Mentions a specific idea from the book.  
* Connects to personal life.  
* Asks a thoughtful question.  
* Responds respectfully to another reader.  
* Shows original thinking.

---

## **7.3 Copy-Paste Rule**

If a reflection is copied from the internet or repeated from another user:

* No points.  
* No badge progress.  
* Reflection may be rejected.  
* Repeated abuse can reduce trust score.

# **8\. Streak System**

Streaks are one of the most important parts of the platform because they build daily habit.

But streaks must be designed carefully. If they are too strict, people quit. If they are too easy, they lose meaning.

---

# **9\. Types of Streaks**

## **9.1 Daily Reading Streak**

This is the main streak.

A user continues the streak by completing the daily reading check-in.

Example:

Day 1 → Day 2 → Day 3 → Day 4

---

## **9.2 Reflection Streak**

This rewards users who not only read but also think.

A user continues this streak by submitting a reflection.

This should be separate from the reading streak.

Why?

Some users may read daily but not reflect daily. We should not punish them too much.

---

## **9.3 Cycle Streak**

This tracks how many reading cycles a user completes in a row.

Example:

Completed 3 reading cycles consecutively

This is important for long-term identity.

---

## **9.4 Weekly Consistency Streak**

This rewards users who complete weekly reading targets.

Example:

Completed weekly target for 4 weeks in a row

This is useful for users who cannot check in daily but still complete reading.

---

# **10\. Streak Rules**

## **10.1 Basic Daily Streak Rule**

A user keeps the daily reading streak if they mark the day’s reading as complete before the daily deadline.

Example deadline:

11:59 PM local time

---

## **10.2 Grace Day Rule**

A strict streak system can discourage users. So the platform should include grace days.

### **Recommended Rule**

Each user gets:

1 grace day per week

Meaning:

* If they miss one day, the streak does not break immediately.  
* The system marks it as a protected day.  
* They must continue the next day.

---

## **10.3 Streak Freeze**

A streak freeze is a special protection item.

Users can earn streak freezes through:

* Completing weekly target.  
* Completing full cycle.  
* Earning badges.  
* Special events.  
* Admin gifts.

### **Rule**

A streak freeze protects one missed day.

Limit:

Maximum 2 unused streak freezes at a time

This prevents people from collecting too many and making streaks meaningless.

---

## **10.4 Catch-Up Rule**

Sometimes users miss reading but want to recover.

Recommended rule:

A user can catch up within:

24 hours

If they complete the missed reading and submit a short catch-up note, the streak can be restored.

But this should be limited.

Suggested limit:

Maximum 2 catch-ups per reading cycle

---

## **10.5 Streak Break Rule**

A streak breaks if:

* User misses a day.  
* No grace day is available.  
* No streak freeze is available.  
* Catch-up window passes.

When streak breaks, do not shame the user.

Use encouraging copy:

**Your streak paused, but your journey did not. Start again today.**

# **29\. Leaderboard System**

Leaderboards can motivate users, but they can also discourage beginners.

So Read & Revive should not use only one big all-time leaderboard.

---

## **29.1 Recommended Leaderboards**

| Leaderboard | Reset | Purpose |
| ----- | ----- | ----- |
| Weekly Reading Leaders | Weekly | Rewards current consistency |
| Current Cycle Leaders | Per cycle | Rewards active participants |
| Top Reflectors | Weekly/monthly | Rewards thinking |
| Book Finishers | Per cycle | Rewards completion |
| Community Builders | Monthly | Rewards encouragement |
| Rising Readers | Weekly | Helps new users appear |
| Published Voices | Monthly | Highlights writers |
| Comeback Readers | Monthly | Celebrates returning users |

---

## **29.2 Avoid All-Time Dominance**

All-time leaderboards can make new users feel hopeless.

If used, all-time should be secondary.

Better:

This Week  
This Cycle  
This Month  
Rising Readers

---

## **29.3 Leaderboard Score Formula**

For a cycle leaderboard, score should not be only total points.

Suggested formula:

Cycle Score \=  
Reading completion points  
\+ Reflection quality points  
\+ Discussion participation points  
\+ Community support points  
\+ Completion bonus

This prevents people from winning only by commenting a lot.

---

## **29.4 Leaderboard Fairness Rules**

* New users should have a separate “Rising Readers” board.  
* Reflections should need approval for high-value points.  
* Spam comments should not count.  
* Admins/moderators should be excluded from competitive boards.  
* Private users can hide from public leaderboard.  
* Leaderboards should reset often enough to keep hope alive.

# **38\. Notification and Motivation Copy**

The platform should motivate without guilt.

## **38.1 Good Notification Copy**

| Situation | Message |
| ----- | ----- |
| Daily reminder | Your next pages are waiting. Keep the circle moving. |
| Streak active | Your reading streak is alive. One small step today. |
| Missed day | Your journey is not over. Continue today and rebuild. |
| Badge earned | You unlocked a new badge. Your consistency is showing. |
| Cycle completed | You finished the cycle. Now let your reflection speak. |
| Reflection prompt | What idea stayed with you today? |
| Closing session | The circle closes soon. Join the final conversation. |

---

## **38.2 Avoid Shame-Based Copy**

Avoid:

You failed.  
You lost everything.  
You are behind everyone.  
You broke your promise.

Use:

Paused, not finished.  
Start again today.  
Your next page still counts.

# **45\. Ethical Gamification Rules**

This is important.

## **45.1 Do**

* Encourage healthy consistency.  
* Celebrate progress.  
* Let users recover after missing days.  
* Keep competition friendly.  
* Protect privacy.  
* Reward meaningful effort.  
* Highlight different types of success.

---

## **45.2 Do Not**

* Shame users for missing days.  
* Make the platform addictive in a harmful way.  
* Make leaderboards the only recognition.  
* Reward spam.  
* Make beginners feel invisible.  
* Publicly expose private reading data.  
* Turn reading into pressure instead of growth.

# **47\. Locked Gamification Principles**

These should be locked.

| Area | Locked Rule |
| ----- | ----- |
| Main purpose | Build reading habits, reflection, community, and contribution |
| Main streak | Daily reading streak |
| Secondary streaks | Reflection streak, weekly consistency streak, cycle streak |
| Grace system | 1 grace day per week |
| Streak freeze | Earnable protection, max 2 stored |
| Points | Separate XP and Reading Points |
| Leaderboards | Weekly/cycle/monthly, not only all-time |
| Badges | Multi-category, not only streak badges |
| Completion | Based on reading \+ reflection, not one click |
| Blog reward | Published articles receive high recognition |
| Anti-spam | Meaningless activity should not earn major points |
| Tone | Encouraging, not shame-based |
| Long-term identity | Reader Passport \+ profile \+ levels |

# **48\. Final Gamification Summary**

Read & Revive’s gamification system should be a **reader development system**, not just a reward system.

It should help users move through this identity journey:

Visitor  
→ New Reader  
→ Circle Reader  
→ Consistent Reader  
→ Reflective Reader  
→ Book Finisher  
→ Published Voice  
→ Circle Guide  
→ Culture Reviver

The long-term goal is to make every reader feel:

**I am not only reading a book. I am building a habit, joining a circle, sharing my voice, and becoming part of a culture.**
